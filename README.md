# Homenagem ao Dia dos Professores | Colégio Novos Tempos

Site estático em HTML, CSS e JavaScript, pronto para GitHub Pages.

## Conteúdo
- 90 pontos na timeline (70 registros anteriores + 20 envios adicionais; 12 envios adicionais repetem fotos já recebidas de forma intencional).
- Todas as fotografias exibidas são derivadas de arquivos reais enviados, sem geração de imagens.
- Logo oficial, narração contínua de aproximadamente 2min59s e vídeo especial.
- Ampliação e navegação entre fotos; versão responsiva.

## Publicação no GitHub Pages
1. Crie um repositório **público** no GitHub.
2. Envie **todo o conteúdo desta pasta**, incluindo `index.html`, arquivos JS/CSS e `assets/`, **para a raiz** da branch `main` (não envie o ZIP como único arquivo).
3. Em **Settings > Pages > Build and deployment**, escolha **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.
4. Aguarde a publicação; o endereço padrão será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Edição
- Textos, palavras, sequência de imagens e vídeo: `conteudo.js`.
- Estilo: `styles.css`; comportamentos: `script.js`.
- Fotos otimizadas: `assets/fotos/foto-01.webp` a `foto-90.webp`.
- Narração: `assets/audio/mensagem-professores-completa.mp3`.
- Vídeo: `assets/videos/homenagem-professores.mp4`.
- Logo: `assets/logo/novos-tempos-oficial.png`.

## Backup
As fotografias originais, antes da conversão WebP, estão no pacote completo `Site_Professores_Timeline_90_Fotos.zip` (separado). Elas não precisam ficar públicas para o site funcionar.

## Direitos e privacidade
Confirme a autorização institucional para divulgação de imagens de professores, funcionários e especialmente estudantes antes de tornar o site público.
